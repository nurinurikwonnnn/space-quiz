# 우주 탐사 퀴즈

우주와 태양계에 관한 10개 질문에 답하는 한국어 퀴즈입니다. 정답 여부에 따른 피드백과 점수, 진행률을 확인하고 마지막에 결과를 볼 수 있습니다. 밝은 테마와 어두운 테마를 지원하며, 별도의 서버나 외부 라이브러리 없이 실행됩니다.

## 로컬에서 실행하기

1. 저장소를 내려받거나 복제합니다.
2. `index.html`을 웹 브라우저에서 엽니다.

빌드나 의존성 설치는 필요하지 않습니다. 원한다면 로컬 개발 서버를 사용해도 됩니다.

## GitHub Pages 배포

`main` 브랜치에 변경 사항이 반영되면 GitHub Actions가 인라인 JavaScript 문법을 확인하고 사이트를 GitHub Pages에 배포합니다. 저장소의 **Actions** 탭에서 배포 상태를 확인할 수 있습니다.
