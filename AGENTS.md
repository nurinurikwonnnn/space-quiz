# Project rules

- Keep the quiz self-contained in `index.html`; do not add a server, build step, or dependencies.
- Write all user-facing quiz content in Korean.
- Preserve the existing light and dark themes and the narrow, centered layout.
- Keep interactions keyboard-accessible, use semantic HTML, and respect reduced-motion preferences.
- Keep feedback, score, progress, and results behavior consistent when changing quiz logic.
- Verify changes in the integrated browser and check inline JavaScript syntax.
